CASH-AI – finales Modell- und Forecast-Update
================================================

DATEIEN ABLAGE
--------------

Diese Dateien nach C:\CashAI kopieren:

- UPDATE_CASH_AI_MODELS.py
- START_MODELL_UPDATE.bat
- START_KOMPLETT_UPDATE.bat
- requirements_models.txt

Die aufbereiteten CASH-AI-Dateien bleiben in:
C:\Ergebniss_XGBoost

Benötigt werden insbesondere:
- 07_Cashflow_Taeglich_Training.csv
- 08_Cashflow_Taeglich_Validierung.csv
- 09_Cashflow_Woechentlich_Training.csv

ERSTER START
------------

Im VS-Code-Terminal:

cd C:\CashAI
python -m pip install -r requirements_models.txt
python UPDATE_CASH_AI_MODELS.py


WAS DER CODE MACHT
------------------

1. Training und bisherige 6-Wochen-Validierung werden für das finale Refit
   zusammengeführt. Nicht freigegebene/unvollständige Wochen bleiben ausgeschlossen.

2. XGBoost:
   - finales Cash-In-Modell
   - finales Cash-Out-Modell
   - Netto-Cashflow = Cash-In - Cash-Out
   - rekursiver Wochenforecast ab der ersten Woche nach dem Datenstichtag

3. SARIMA:
   - finales Cash-In-Modell
   - finales Cash-Out-Modell
   - Netto-Cashflow = Cash-In - Cash-Out
   - verwendet dieselbe wöchentliche Historie wie XGBoost

4. Für beide Modelle werden erzeugt:
   - tägliche Prognose
   - wöchentliche Prognose
   - monatliche Prognose

   Die native Modellprognose ist wöchentlich.
   Tageswerte werden aus dem Wochenforecast mit historischen
   Wochentagsanteilen verteilt. Monatswerte werden anschließend
   aus den Tageswerten summiert.

5. Realisierte Cashflows werden ebenfalls ausgegeben:
   - täglich
   - wöchentlich
   - monatlich

6. Für Power BI entsteht ein stabiler Pfad:
   C:\CashAI\Ergebnisse\AUTO_UPDATE\PowerBI\PowerBI_Cashflow_Gesamt.csv

   Die Datei enthält:
   - IST / Realisiert
   - XGBoost / Prognose
   - SARIMA / Prognose
   - täglich / wöchentlich / monatlich
   - Cash-In / Cash-Out / Netto-Cashflow

POWER BI
--------

Power BI sollte immer auf diese Datei zeigen:

C:\CashAI\Ergebnisse\AUTO_UPDATE\PowerBI\PowerBI_Cashflow_Gesamt.csv

Nach einem neuen Modelllauf wird genau diese Datei überschrieben.
In Power BI Desktop danach "Aktualisieren" wählen.

Für eine vollständig automatische Aktualisierung im Power BI Service
wird zusätzlich ein Gateway oder eine Cloud-Ablage wie OneDrive/SharePoint
benötigt.


WICHTIG
-------

Die ursprüngliche 6-Wochen-Validierung sollte für die dokumentierte
Modellauswahl/Modellbewertung archiviert bleiben. Sie wird nur für das
finale operative Refit wieder in die Trainingshistorie aufgenommen.

Die XGBoost-Konfiguration im Skript verwendet:
- n_estimators = 300
- max_depth = 4
- learning_rate = 0.05

Falls euer final ausgewähltes XGBoost-Modell noch weitere bewusst gesetzte
Hyperparameter hatte, sollten diese im Block XGB_PARAMS ergänzt werden.
